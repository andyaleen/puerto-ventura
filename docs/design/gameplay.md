# Gameplay

## Core loop

```
Explore → Gather → Earn → Upgrade tools → Restore buildings
  → Unlock NPCs → Expand businesses → Reveal history → Unlock regions → Repeat
```

## Session feel

Short sessions should still leave a visible mark: a gathered stack, a paid restoration, a cleared path, or a new area opened.

## Systems at a glance

| System | Role | Priority |
|--------|------|----------|
| Restoration | Core progression; changes maps and unlocks content | Highest |
| Exploration / regions | Modular world travel | Highest (world shell) |
| Gathering | Feeds economy and restorations | High |
| Fishing | Major pillar at Beach / Harbor | High (after restoration wired) |
| Economy | Money + resources fund upgrades and projects | High |
| Farming | Present on farm/home; should not dominate | Medium |
| Mining | Later rocky / cave regions | Later |
| NPCs / friendship | Return as districts revive | Later |
| Combat | TBD — keep light if present; do not dominate cozy tone | TBD |

## Player verbs (early)

- Walk between regions
- Collect resources
- Interact (`E`) with pickups and future restoration sites
- Spend toward restorations
- Unlock new paths and regions

## Constraints

- Prefer multiple achievable goals at once over a single forced quest rail.
- Visible world change beats invisible stat bumps.
