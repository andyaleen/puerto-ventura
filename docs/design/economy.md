# Economy

## Purpose

Money and resources exist to fund **restorations**, tool upgrades, and reopened businesses—not endless inventory hoarding.

## Currencies / stores (prototype)

`GameState` already tracks:

- Money
- Day
- Resources (e.g. beach pickups like shells / wood)

## Intended sinks

- Restoration project costs
- Tool upgrades
- Shop purchases once businesses reopen

## Intended sources

- Gathering
- Fishing (major)
- Farming (supporting)
- Mining (later)
- Selling goods through restored shops

## Design rules

- Early restorations should be affordable after a short gather session.
- Costs should teach resource variety without requiring spreadsheets.
- Visible spend → visible world change.

## Implementation status

Money/day/resources exist; spending and shops are largely unwired.
