# Crafting

## Role

Supporting system for tools, repair materials, and restoration requirements—not a primary identity loop.

## Likely uses

- Tool crafting / upgrades (hoe, rod, pickaxe, axe, etc.)
- Conversion of raw gathers into restoration materials
- Furniture / decor for restored spaces (later)

## Design rules

- Prefer few clear recipes that unlock with progression.
- Crafting should unblock restoration and exploration, not compete with them for attention.
- Keep UI simple; avoid deep factory complexity.

## Implementation status

Not implemented. Spec TBD once restoration + gather loops are playable.
