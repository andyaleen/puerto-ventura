# User Interface (UI)

The user interface in **Puerto Ventura** should feel calm, intuitive, and unobtrusive. The island itself is the focus of the player's attention, not the HUD. Information should always be easy to find when needed, but remain largely out of the way during normal gameplay.

The UI should reinforce the cozy atmosphere through clean layouts, subtle animations, readable typography, and simple interactions. Players should never feel overwhelmed by menus or constantly monitor dozens of stats.

# UI Philosophy

The UI follows several guiding principles:

- Cozy and highly readable.
- Minimal HUD clutter.
- One clear purpose per screen or panel.
- Important information always within one or two clicks.
- Consistent interaction prompts throughout the game.
- Smooth fade transitions between regions reinforce that the player is traveling across the island.

The interface should support gameplay—not compete with it.

# In-Game HUD

While exploring the island, only essential information is visible.

The HUD displays:

- Current Day(island calendar)
- Current Money
- Quick Inventory / Equipped Tool Bar
- Health (when applicable)
- Stamina
- Active interaction prompts

Everything else remains hidden until requested.

This allows players to appreciate Puerto Ventura's environments without unnecessary interface clutter.

# Pause Menu

The Pause Menu serves as the player's primary hub.

From here they can access:

- Inventory
- Equipment
- Relationship Menu - heart level and known favorite gifts
- World Map
- Journal
- Crafting Recipes
- Food recipes known and unknown
- Fish Collection
- Quest Log
- Restoration Progress
- Settings
- Save Game
- Exit to Main Menu

The layout should be simple, clean, and easy to navigate.

# Inventory

The inventory displays:

- Resources
- Crafting materials
- Tools
- Weapons
- Food
- Quest items
- Gifts
- Building materials

Items should use clear icons, concise descriptions, and consistent categories.

Players should immediately understand what they own without needing to memorize symbols or resource names.

# Relationship Menu

The relationship screen tracks every resident the player has met.

Each character page displays:

- Portrait
- Friendship level
- Romance status (if applicable)
- Birthday
- Favorite gifts
- Loved gifts
- Liked gifts
- Disliked gifts
- Quest history
- Personal notes
- Unlocked dialogue events

Unknown information appears as question marks until discovered naturally.

# World Map

The map gradually fills in as the player explores.

Players can:

- View discovered regions
- See restoration progress
- Hover over buildings to view their names
- Identify districts
- Locate important NPCs (later upgrades)
- View unlocked travel routes

Important landmarks should be clearly recognizable while maintaining the artistic style of the world.

# Journal

The Journal acts as the player's memory.

Sections include:

- Current quests
- Completed quests
- Restoration milestones
- Island history
- Ancient discoveries
- Character notes
- Collected documents
- Lore entries

Rather than presenting a wall of text, the journal should feel like an explorer's notebook that grows alongside the player's adventure.

# Crafting & Recipe Book

The recipe menu organizes everything the player has learned.

Categories include:

- Tool recipes
- Building materials
- Furniture
- Cooking
- Restoration materials
- Equipment

Unknown recipes remain hidden until unlocked through exploration, NPCs, or story progression.

# Fish Collection

Every fish discovered is recorded in the Island Fishing Journal.

Each entry displays:

- Illustration
- Name
- Description
- Habitat and times caught (morning, afternoon, night)
- Largest catch


Missing fish remain silhouetted, encouraging exploration and collection.

# Quest Log

The Quest Log tracks:

- Main story objectives
- Restoration projects
- Character requests
- Community projects
- Exploration goals

Objectives should clearly communicate what the player needs to accomplish without over-explaining solutions.

# Restoration Interface

Every restoration project presents a dedicated confirmation panel.

The panel displays:

- Project description
- Required money
- Required materials
- Current progress toward requirements
- Rewards
- Confirmation button

Whenever possible, players should preview how the completed restoration will change the world before committing resources.

# Locked Area Messaging

Rather than simply displaying "Area Locked," Puerto Ventura explains *why* the player cannot proceed.

Examples include:

- "I'll need a stronger pickaxe to break through this rock."
- "Those vines are too thick to cut."
- "This bridge will need to be rebuilt first."
- "The cliff is too steep to climb."
- "Whatever powered this ancient doorway has long since stopped working."

These messages naturally communicate future goals while encouraging players to return later.

# Dialogue Interface

Conversations should feel personal and easy to follow.

The dialogue interface displays:

- Character portrait
- Character name
- Dialogue text
- Player dialogue choices
- Relationship indicators (optional)
- Gift button (when appropriate)

Important story conversations may include larger illustrated portraits to emphasize emotional moments.

Dialogue options should remain concise while allowing players to express different personalities where appropriate.

# Fishing UI

The fishing interface should remain clean and approachable.

It displays:

- Casting indicator
- Bite notification
- Simple timing challenge
- Fish stamina/progress meter (if implemented)

The goal is to create a relaxing minigame that complements the cozy atmosphere instead of introducing unnecessary stress.

# Notifications & Feedback

The game should provide satisfying feedback without interrupting gameplay.

Examples include:

- New area discovered
- Relationship increased
- Recipe learned
- Restoration completed
- Tool upgraded
- Museum donation made
- Quest completed

Notifications should appear briefly and disappear naturally without requiring player interaction.

# Transitions

Moving between major regions should use short fade transitions to communicate travel while maintaining immersion.

The destination area's name can briefly appear during the transition, reinforcing the feeling of exploring a large interconnected island.

Examples:

**Entering: Jungle**

*Fade to black*

**Jungle**

*Fade back in*

These transitions also provide opportunities to stream and load the next area behind the scenes.

# Save & Settings

The pause menu includes straightforward save functionality.

Players can:

- Save Game
- Load Game
- View Save Slots
- Adjust Audio
- Adjust Graphics
- Rebind Controls
- Accessibility Options
- Return to Main Menu

Saving should be quick, reliable, and available whenever the player is outside of major story events.

# Long-Term Vision

The UI should feel almost invisible during normal gameplay. Players spend most of their time looking at Puerto Ventura itself—not menus or icons. Every screen has a single clear purpose, every interaction follows consistent rules, and every piece of information is easy to find when needed. The result should be an interface that supports exploration, restoration, and storytelling while preserving the relaxed, welcoming atmosphere that defines Puerto Ventura.
