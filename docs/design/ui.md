# UI

## Prototype HUD

Region HUD shows:

- Current region name
- Day
- Money
- Resources
- Exit / neighbor list (as implemented)

## Principles

- Cozy and readable; avoid dashboard clutter
- One job per panel
- Interact prompt consistency (`E`)
- Fade transitions communicate region travel
