# Farming

## Role

Present and satisfying, but **must not dominate**. Farm/home supports the restoration fantasy; it is not the whole game.

## Fantasy

A small beach-adjacent farm/home plot: crops, maybe animals later, storage, and a place that feels like “yours” between island expeditions.

## Loop sketch

1. Till / plant / water / harvest on farm/home
2. Sell crops or use them in restorations / cooking / gifts
3. Expand modestly as tools and land unlock

## Design rules

- Keep plot size and crop list manageable for v1.
- Farming income should not obsolete fishing + exploration.
- Seasonal depth is optional; prefer clarity over complexity early.

## Implementation status

Farm/home region not fully established in registry yet. No farming systems implemented.

## Priority

After Beach/farm region split and basic restoration loop.
