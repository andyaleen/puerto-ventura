# Characters

## Player

Inherits a beach cottage / farm-home foothold on the island. Motivated by restoration, curiosity, and rebuilding community—not conquest.

## NPCs (design intent)

NPCs return and deepen as districts revive. They should feel like they have lives that evolve with the town—not static quest vendors.

### Planned relationship layers

- Friendship
- Optional romance (later)
- Roles tied to restored businesses (shopkeepers, fishers, caretakers, etc.)

## Arrival timing

Prefer unlocking characters **after** (or as) relevant restorations complete, so people feel like a consequence of healing the island.

## Implementation status

Not implemented yet. No dialogue system in the prototype.
