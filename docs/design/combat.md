# Combat

## Status

**Undecided / low priority.** Puerto Ventura is a cozy restoration life sim. Combat must not redefine the fantasy.

## Possible directions (not chosen)

1. **None** — soft obstacles (blocked paths, puzzles, tool gates) only
2. **Very light** — scare-off wildlife / cursed-area hazards with simple tools
3. **Avoidance-focused** — hazards in deep jungle / cursed / volcano without a full battle system

## Design rules if combat exists

- Keep encounters rare and readable.
- Prefer tools and preparation over twitch difficulty.
- Never make combat the main money or progression path.

## Implementation status

Not implemented. No combat systems in the prototype.

## Decision needed

Confirm before Phase 4–5 systems work whether cursed / deep jungle content needs combat or only traversal puzzles.
